# 데이터 모델

## 기본 원칙

화면 표시 모델과 영속화 모델을 분리한다. 시간은 ISO 8601 문자열로 저장하고
지속 시간은 초 단위를 사용한다. 모든 사용자 소유 데이터에는 실제 저장
단계에서 `userId`를 포함한다.

## 주요 엔터티

- `User`: 이름, 이메일, 레벨, 경험치, 포도알, 선택한 캐릭터와 챕터.
- `StudyCategory`: 공부 주제 이름, 색상, 누적 공부 시간.
- `StudySession`: 시작과 종료 시각, 실제 공부 시간, 획득 페이지와 책.
- `BookProgress`: 주제별 완성 책 수와 현재 책의 남은 페이지.
- `SpaceProgress`: 현재 공간, 전체 책 수, 책장 레벨과 공간 해금 상태.
- `DailyQuest`: 날짜별 퀘스트, 완료 시각과 보상.
- `CharacterState`: 캐릭터의 청결도, 수분, 컨디션.
- `RoomState`: 방의 청결도, 선택 가구와 해금 아이템.
- `Achievement`: 업적 종류, 목표값, 달성 시각, 축하 화면 확인 여부.
- `Magazine`: 일간, 주간, 월간 기간과 요약 데이터, 표지 이미지 경로.

현재 TypeScript의 최소 화면 모델은 `src/models/index.ts`에 있다. 백엔드를
선정하면 ID 생성 방식, 삭제 정책, 시간대 경계, 매거진 요약 스키마를
마이그레이션 문서에 추가한다.
