# 구현 계획

## 선택한 기술 기반

Expo SDK 54, React Native, TypeScript를 사용한다. iOS와 Android를 하나의
코드베이스로 개발하고 Expo Router의 파일 기반 라우팅으로 화면 소유권을
명확하게 나눈다. 서버가 정해지기 전까지 UI, 도메인 타입, 저장 로직을
분리한다.

## 구현 단계

1. **기반 구조(완료)**: 4개 탭, 공통 테마와 컴포넌트, 기능별 폴더,
   핵심 타입과 성장 설정값.
2. **로컬 MVP**: 온보딩, 로컬 저장소, 퀘스트 상태, 시작 시각 기반 공부
   타이머와 백그라운드 복구.
3. **성장 시스템 연결**: 페이지와 책 환산, 공간 해금, 캐릭터와 방 변화,
   누적 100시간 업적.
4. **기록 시스템**: 일간, 주간, 월간 통계와 매거진 아카이브, 이미지
   내보내기.
5. **백엔드 연동**: 인증, 데이터 동기화, 마이그레이션, 알림.

## 결정이 필요한 항목

- 인증 공급자와 백엔드 데이터베이스 선정.
- 캐릭터와 방 그래픽의 제작 방식 및 라이선스.
- 책장, 공부방, 도서관의 해금 기준 사용자 검증.
- 일간 매거진 생성 시각과 주간 시작 요일.
