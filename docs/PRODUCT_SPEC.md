# MoveOn 제품 명세

## 제품 정의

현실의 좋은 행동을 캐릭터, 책, 공간의 성장으로 연결해 사용자가 보낸 시간을
눈에 보이게 만드는 라이프 시뮬레이션형 자기관리 앱이다.

## MVP 원칙

- 기록량보다 행동 이후의 긍정적인 변화를 강조한다.
- 입력 부담을 낮추고 비교, 경쟁, 소셜 기능은 넣지 않는다.
- 공부 10분마다 1페이지, 6페이지마다 책 1권으로 환산한다.
- 10분 미만 세션은 기록하되 페이지에는 반영하지 않는다.
- 반복 퀘스트를 완료하면 캐릭터 또는 방 상태가 즉시 개선된다.

## 주요 화면

1. 홈: 캐릭터 상태, 자동 퀘스트 3개, 레벨과 재화, 오늘의 진행 상황.
2. 공부: 공부 주제와 목표 시간 선택, 책 진행 시각화, 타이머 진입점.
3. 방: 캐릭터, 가구, 책장과 공간 해금 진행 상황.
4. 스토리: 일간, 주간, 월간 매거진 아카이브.

## 이번 단계의 범위

실행 가능한 화면 골격, 공통 테마, 도메인 타입, 성장 설정값을 제공한다.
로그인, 데이터베이스, 실제 타이머, 매거진 자동 생성, 알림, 결제와 소셜
기능은 후속 단계에서 구현한다.

## MVP 제외 기능

친구, 피드, 랭킹, 채팅, GPS, OCR, AI 생성, 타인의 방 방문, 실제 결제와
소셜 공유 피드는 구현하지 않는다.
