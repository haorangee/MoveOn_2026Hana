# MoveOn

현실의 행동을 캐릭터, 책, 공간의 성장으로 보여주는 모바일 자기관리 앱입니다.

## 실행 방법

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
cd "C:\Users\pps41\OneDrive\문서\MoveOn"
npm install
npx expo start --clear
```

최초 설치가 끝난 다음부터는 `npm start`로 실행할 수 있습니다.

정적 타입 검사는 `npm run typecheck`로 실행합니다. 제품 범위는
`docs/PRODUCT_SPEC.md`, 개발 순서는 `docs/IMPLEMENTATION_PLAN.md`를
참고하세요.
